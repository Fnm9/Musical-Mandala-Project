## Description
Musical Mandala is an interactive generative art project built in Python using Pygame. 
The program creates layered geometric mandala patterns that dynamically shift colors based on mouse movement while ambient WAV music plays in the background. 
The project combines mathematics, symmetry, animation, sound, and user interaction to create a meditative digital visual experience. Also, there is a music file in this program and it plays music on loop.
